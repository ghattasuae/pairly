# Third-party notices

Pairly AI is open source (AGPL-3.0) with a commercial license option. It uses the third-party components listed below. Each one stays under its own license.

This file is generated by `scripts/third_party_notices.py`. Do not edit it by hand. To refresh it, install all dependencies and run:

```sh
uv run python scripts/third_party_notices.py -o NOTICE.md
```

The script reads Python package metadata from the current environment and JavaScript packages from `pnpm-lock.yaml`. A license shown as UNKNOWN means the package did not publish license metadata, or it is not installed on this machine. Check it by hand before release.
