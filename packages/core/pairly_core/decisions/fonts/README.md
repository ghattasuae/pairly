# Receipt font

`DejaVuSans.ttf` is a subset of DejaVu Sans 2.37 (Latin, Latin-1, general punctuation,
Arabic and the Arabic presentation forms), made with `pyftsubset` from fontTools. The
decision receipt PDF embeds it, so one file renders both English and Arabic.
